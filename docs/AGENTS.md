# 🚀 3팀 프로젝트 개발 및 협업 가이드

## 1. Git 커밋 컨벤션 (Commit Message 규칙)
우리 팀은 커밋할 때 제목 맨 앞에 아래 말머리를 붙이기로 약속합니다.
- `Feat:` 새로운 기능 추가 
- `Fix:` 버그 수정
- `Docs:` 문서 수정 (README, 가이드 문서 등)
- `Refactor:` 코드 리팩토링 (기능은 같은데 코드만 깔끔하게 바꿈)
- `Chore:` 패키지 설치나 자잘한 설정 변경

## 2. 데이터 정제 대원칙
- `country` 컬럼이 `NULL`이거나 `Unknown`인 데이터는 분석 및 모델링에서 제외합니다. 
- 대용량 데이터 유실을 막고 메모리를 아끼기 위해, 최대한 MySQL(DBManager) 단계에서 `WHERE country IS NOT NULL`로 필터링한 후 파이썬으로 가져옵니다.

## 3. 코드 모듈화 규칙
- 실험적인 코드는 `notebooks/` 폴더에서 자유롭게 주피터 노트북으로 작성하되, 완성된 전처리/DB 관련 함수는 `data/api/`나 `data/db/` 폴더 안에 파이썬 파일(`.py`)로 이관하여 관리합니다.
