# 3. 평가 지표 설명
Accuracy

전체 데이터 중 모델이 올바르게 예측한 비율로, 전체적인 예측 정확도를 의미한다.

Precision

모델이 “취소”라고 예측한 것 중 실제로 취소인 비율로, 오탐(False Positive)을 얼마나 줄였는지를 나타낸다.

Recall

실제 취소 고객 중 모델이 얼마나 정확하게 찾아냈는지를 의미하며, 미탐(False Negative) 감소에 중요한 지표이다.

F1-score (핵심 기준)

Precision과 Recall의 조화 평균으로, 두 지표 간 균형을 평가하는 지표이다.
본 프로젝트에서는 클래스 불균형 및 취소 고객 탐지 중요성을 고려하여 주요 평가 기준으로 사용하였다.

> 본 프로젝트에서는 예약 취소 고객을 효과적으로 식별하기 위해 F1-score를 주요 평가 지표로 설정하였다.
